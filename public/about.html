ABOUT THE PLATFORM

A shared space for class life.

CLASS SPHERE — HEIST is being built as a class management and communication portal for Pwani University. It brings academic information, timetable updates, learning materials and class notices into one place.

PURPOSE

Keep class information together.

Students can find the information and approved resources they need for class.

PRIVACY

Share with care.

Student details and photographs are shown publicly only when approved.

SCOPE

Built to grow.

Administrators can extend the academic catalogue and update class information over time.

Official class mission, vision, leadership and representative details have not yet been supplied, so they are not published here.
